# Сценарий демонстрации для жюри

Длительность — около 5 минут. Демонстрация работает локально, платная модель по умолчанию не используется.

## Подготовка (за 15 минут до показа)

```bash
# 1. Backend: офлайн, без ключа
python -m uvicorn specguard.api:app --host 127.0.0.1 --port 8000 --workers 1

# 2. Frontend
cd frontend && npm run dev        # http://127.0.0.1:5173
```

- Перезапустите backend прямо перед показом. Сессии хранятся в памяти, их не больше 24, и при долгой репетиции лимит может исчерпаться («Достигнут лимит сессий»).
- Держите под рукой файлы `frontend/e2e/fixtures/sample-tz.md` (синтетическое ТЗ с намеренными дефектами) и `frontend/e2e/fixtures/revision-tz.md` (вторая редакция).
- Откройте запасные материалы в соседних вкладках (раздел «Запасной вариант» ниже).
- Браузер — в полноэкранном режиме, масштаб 100%.

> **Честность.** Перед показом скажите вслух: «Сейчас работает офлайн-режим: формальные проверки без языковой модели, на синтетическом документе. Результаты DeepSeek по официальному ТЗ мы покажем из сохранённого прогона». Не выдавайте сохранённый отчёт за новый живой анализ.

## Шаги

| # | Действие | Что сказать |
|---|---|---|
| 1 | Откройте главную страницу | «SPEC закреплён в боковой панели. Взгляд следует за курсором с чувствительностью 70%» — проведите курсором. |
| 2 | Перетащите `sample-tz.md` в зону загрузки, выберите «Офлайн», нажмите «Начать анализ» | «SPEC меняет состояние по реальным событиям сервера: документ получен → извлечение → проверка доказательств → отчёт готов». |
| 3 | Обзор | Вердикт «не определена», и это честно: офлайн-покрытие неполное. Покажите 8 требований и 6 замечаний. |
| 4 | Требования → выберите SG-201 | Реестр со стабильными ID, цитата, связанное замечание «Не найдено требование SG-409». |
| 5 | Противоречия → «Несовместимые нижняя и верхняя границы» | SG-602 («не более 20») против SG-601 («не менее 40»). |
| 6 | Вкладка «Источник» → щёлкните по цитате | Первоисточник открывается с подсвеченной цитатой. «Без цитаты находки не бывает». |
| 7 | Двойной щелчок по SPEC | Справа открывается Copilot. Нажмите Esc и откройте снова — это тоже штатное поведение. |
| 8 | Спросите: «Какой размер пакета записей?» | Ответ со ссылками на строки 17 и 18. Это офлайн-поиск, он помечен в ответе. |
| 9 | Выберите назначение «Новая редакция» и прикрепите `revision-tz.md` и `sample-tz.md` | Появятся две карточки со статусом «текст извлечён». Удалите одну крестиком. |
| 10 | Нажмите «Черновик исправления SG-602» | В офлайн-режиме Copilot объяснит, что черновики делает DeepSeek с согласия пользователя. Затем покажите готовый черновик из запасного материала (шаг 12). |
| 11 | Отчёт → «Скачать Markdown» | Русский отчёт с паспортом прогона, реестром, проверками и итогом. |
| 12 | Откройте официальный отчёт (запасной материал) | «Это сохранённый прогон DeepSeek по выданному ТЗ: 54 из 54 требований, 124 из 124 блоков, 12 подтверждённых находок, 176 проверенных доказательств». |

## Живой режим DeepSeek (только с отдельного разрешения владельца ключа)
Включайте его, только если владелец ключа заранее согласился на расход. Для этого на сервере нужно задать `SPECGUARD_LIVE=1` и `DEEPSEEK_API_KEY`. В интерфейсе выберите «DeepSeek» и отметьте согласие. Задайте низкие потолки: `SPECGUARD_RUN_TOKENS` и `SPECGUARD_GLOBAL_TOKENS`. Не включайте живой режим на публичном адресе.

## Запасной вариант (если что-то пошло не так)
1. **Скриншоты приложения:** `docs/release/screenshots/` (реальное приложение, офлайн-режим).
2. **Официальный прогон DeepSeek:** отчёт `fd9bf1615ce04dc09e5f889bd2613f4b`, SHA-256 `3fa9cef9aef328bc6a6277b280e13c7c8ef1c3185c2a4ea173d02a9e70f93d97`. Файлы лежат вне Git на Mac владельца: `Downloads/SpecGuard AI Review and Release/official`. Перед показом скопируйте их на демо-машину. Называйте его так: **«сохранённый прогон от 26.11.2026»**.
3. **CLI без интерфейса:**
   ```bash
   python -m specguard validate --offline --input frontend/e2e/fixtures/sample-tz.md --output /tmp/report.md
   ```

## Если что-то сломалось
| Симптом | Действие |
|---|---|
| «Достигнут лимит сессий» | Перезапустите backend. |
| «Для защищённого разбора PDF…» | Сервер работает на Windows: используйте Markdown или Linux/macOS. |
| «Сервер не настроен для внешнего анализа» | Это ожидаемо в офлайн-режиме. Объясните, что живой режим включается только на сервере. |
| SPEC не двигается | Проверьте флажок «Анимация SPEC» и системную настройку «уменьшить движение». |
