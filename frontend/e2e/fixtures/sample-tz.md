# ТЗ: мобильный банк — уведомления и выписки

Синтетический документ для проверки интерфейса SpecGuard. Содержит намеренные дефекты.

## Очередь выписок

- SG-101: Система должна сохранять время постановки выписки в очередь в UTC.
- SG-101: Система должна отправлять уведомление после готовности выписки.

## Журнал операций

- SG-501: Система должна хранить журнал операций в течение TBD дней.

## Пакетная выгрузка

- SG-201: Система должна форматировать выгрузку согласно SG-409.
- SG-601: Размер пакета должен быть не менее 40 записей.
- SG-602: Размер пакета должен быть не более 20 записей.

## API

- SG-301: GET /notifications/{id} должен удалять запрошенное уведомление и возвращать 204 No Content.
- SG-401: GET /categories/{id} должен возвращать 404 OK при отсутствии категории.
